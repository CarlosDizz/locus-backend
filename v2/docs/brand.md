# Locus control-panel visual language

The control panel is an editorial operations desk, not a generic SaaS dashboard.

## Foundation

- Display type: Fraunces.
- Interface type: Manrope.
- Cream: `#F6F0E7`.
- Sand: `#E8DDC7`.
- Terracotta: `#B86A4B`.
- Cartographic blue: `#2F5D62`.
- Field green: `#6C8A64`.
- Ink: `#1F2A2E`.

## Direction

- Warm layered surfaces with subtle paper and map references.
- Strong editorial headings and dense but calm operational tables.
- Terracotta marks intentional actions; blue-green communicates navigation and state.
- Large radii are reserved for summaries and workspaces, not every control.
- Motion communicates publication, routing, and live session flow rather than decoration.
- Charts use the brand palette and remain readable without relying on color alone.

The mobile visual system is the source, but desktop composition prioritizes scanning,
comparison, and safe operational actions.
